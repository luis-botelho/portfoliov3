# Luis Botelho / Portfólio

Portfólio profissional de Luis Fellype Botelho, desenvolvedor Full-Stack e estudante de Engenharia de Software.

## Stack

Next.js App Router, React, TypeScript, Sass/CSS Modules, next/font, Vercel Analytics e Speed Insights. Os projetos são dados tipados em `src/data/projects.ts` e cada case study é gerado estaticamente em `/projetos/[slug]`.

## Scripts

- `pnpm dev`: desenvolvimento
- `pnpm lint`: ESLint
- `pnpm stylelint`: Stylelint para SCSS
- `pnpm test`: Vitest
- `pnpm test:e2e`: Playwright e axe
- `pnpm build`: build de produção

O portfólio distingue produto publicado, MVP, construção e fundação. Imagens e informações sem confirmação não são inventadas: os assets editoriais precisam ser adicionados quando estiverem disponíveis.

Defina `NEXT_PUBLIC_SITE_URL` no deploy para gerar canonical, sitemap e robots com a URL pública real.
